# فۆڵدەرا ڤیدیۆیان

ئەگەر خۆت ڤیدیۆ میوانداری دکەی، ل ڤێرێ فایلێن MP4 یێن مۆڵەتپێدراو دابنێ. نموونەی لینکەکا ئەڵقەیێ ل `app.js`:

```js
episodeUrls: ['./media/series-s01e01.mp4']
```

هەر خانەیەکا `episodeUrls` ب هەمان ڕیزبەندییا خانەیێن `episodes` دابنێ. ژ بۆ خزمەتگوزاریەکا گشتی ب بینەرێن زێدە، خزمەتگوزاریەکا میوانداریا ڤیدیۆیێ یان CDN بکاربینە کو پەخشکرن و باندویدسییا پێدڤی دابین بکەت؛ هەمی هۆستێن وێبێ ب قەبارەیێ فایل و باندویدسییا ڤیدیۆیێ ڕێ نادەن. تەنێ ڤیدیۆیێن کو مۆڵەتا بڵاوکرنا وان هەیە بکاربینە.
